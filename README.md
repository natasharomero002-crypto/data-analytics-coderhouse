# RetailPro — Proyecto de Análisis de Datos

## Descripción
RetailPro es un proyecto académico de análisis de datos orientado al estudio de ventas. El trabajo incluye consultas SQL para resumir resultados comerciales, ordenar productos por facturación y relacionar información de ventas con clientes, productos y categorías.

## Herramientas
- **SQL Server / SQL:** creación y consulta de la base de datos.
- **GitHub:** almacenamiento y versionado de los archivos del proyecto.
- **Power BI:** desarrollo de modelos de datos, métricas DAX y visualizaciones.

## Archivos
- `ventas_tech_db.sql`: script de creación y preparación de la base de datos.
- `m4_consultas_negocio.sql`: consultas de análisis de negocio, como el resumen mensual y el ranking de productos.
- `m5_consultas_joins.sql`: consultas que relacionan las tablas mediante `INNER JOIN` y `LEFT JOIN`.

## Cómo ejecutar los archivos
1. Abrir SQL Server Management Studio (SSMS) y conectarse a una instancia de SQL Server.
2. Abrir `ventas_tech_db.sql` y revisar el contenido antes de ejecutarlo para crear o preparar la base de datos.
3. Abrir `m4_consultas_negocio.sql` y ejecutar las consultas de negocio.
4. Abrir `m5_consultas_joins.sql` y ejecutar las consultas de relaciones entre tablas.
5. Revisar los resultados y comprobar que correspondan con los datos cargados.

> **Nota:** Los scripts deben ejecutarse en una instancia de SQL Server. Si la base ya existe, revisar `ventas_tech_db.sql` antes de volver a ejecutarlo.

## Objetivo
Documentar el trabajo realizado en RetailPro y facilitar que otra persona pueda comprender la estructura del proyecto, identificar los archivos principales y continuar el análisis.
